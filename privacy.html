Política de Privacidade — Ren-Search 蓮

Última atualização: 2 de julho de 2026

Esta política descreve quais dados o bot de Discord Ren-Search (蓮) acessa e como eles são tratados.

Quais dados são acessados

Quando um usuário executa o comando /ren, o bot lê a atividade "Ouvindo Spotify" exposta pela presença do Discord daquele usuário (não usamos a API oficial do Spotify). Isso inclui:

  • Título da música
  • Nome do artista
  • Um identificador de sincronização da faixa (syncId), fornecido pelo próprio Discord

O bot não lê o conteúdo de mensagens, arquivos, DMs ou qualquer outro dado além da presença descrita acima.

Como esses dados são usados

Título e artista são usados apenas para consultar bases de dados públicas de terceiros — AnimeThemes, AniList e Jisho — e identificar se a música pertence a um anime. Nenhum dado de identificação do usuário (nome, ID de conta, etc.) é enviado a esses serviços.

Armazenamento e retenção

Os resultados são mantidos apenas em cache em memória, associados ao syncId da faixa:

  • 30 minutos para resultados encontrados
  • 1 hora para resultados não encontrados

Não há banco de dados persistente. O cache é perdido automaticamente ao expirar ou quando o processo do bot reinicia. Nenhum dado é armazenado permanentemente, vendido ou compartilhado com terceiros para fins de publicidade ou análise.

Servidores autorizados

O bot pode manter uma lista interna de servidores (guilds) autorizados a utilizá-lo. Essa lista contém apenas identificadores de servidor do Discord, usados exclusivamente para controle de acesso ao próprio bot.

Seus direitos

Como nenhum dado pessoal é retido além da janela de cache descrita acima, não há dados de usuário para solicitar exclusão. Dúvidas podem ser enviadas para o contato abaixo.

Alterações a esta política

Esta política pode ser atualizada conforme o bot evolui. A data da última atualização está sempre indicada no topo desta página.
